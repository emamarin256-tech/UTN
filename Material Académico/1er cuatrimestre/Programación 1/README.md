# Programación 1

## Descripción

La asignatura **Programación 1** introduce los fundamentos de la programación utilizando Python como lenguaje principal. A lo largo de la cursada se desarrollan los conceptos necesarios para diseñar algoritmos, representar y manipular datos, controlar el flujo de ejecución y organizar programas mediante funciones.

Se trabaja progresivamente desde las estructuras básicas hasta el manejo de estructuras de datos complejas, excepciones, archivos y recursividad. También se incorporan herramientas de desarrollo y conceptos de trabajo colaborativo mediante Git y GitHub.

## Contenidos

La materia se organiza en diez módulos:

| Módulo | Contenidos principales |
|---|---|
| **1. Estructuras secuenciales** | Algoritmos, variables, tipos de datos, operadores, instrucciones de salida y diagramas de flujo. |
| **2. Estructuras condicionales** | Operadores relacionales y lógicos, condicionales simples, dobles, anidados y ternarios. |
| **3. Estructuras repetitivas** | Bucles `for` y `while`, iteraciones y pruebas de escritorio. |
| **4. Introducción al trabajo colaborativo** | Fundamentos de Git y GitHub, repositorios, commits, ramas, clonación, pull requests y resolución de conflictos. |
| **5. Listas** | Creación, acceso, modificación y recorrido de listas, métodos integrados, listas anidadas y matrices. |
| **6. Funciones** | Subprogramas, funciones, parámetros, variables locales y devolución de resultados. |
| **7. Estructuras de datos complejas** | Listas, matrices, pilas, colas, tuplas, diccionarios e introducción a objetos. |
| **8. Manejo de errores** | Excepciones en Python y utilización de `try`, `except`, `else` y `finally`. |
| **9. Manejo de archivos** | Persistencia de datos, lectura y escritura de archivos de texto y CSV, procesamiento y organización de información. |
| **10. Recursividad** | Concepto de recursividad, caso base, caso recursivo y aplicación en la resolución de problemas. |

## Trabajos y actividades

Durante la cursada se realizan actividades y ejercicios prácticos destinados a aplicar los conceptos desarrollados en cada módulo.

En este repositorio se incorporan los ejercicios de cierre de los módulos y las actividades disponibles. Cabe aclarar que los ejercicios correspondientes a los módulos 1 y 2 no se encuentran adjuntos, ya que fueron realizados durante el curso introductorio a la materia y no se dispone de esos archivos.

Por otra parte, el módulo 4, dedicado al trabajo colaborativo, no contó con un trabajo práctico de desarrollo tradicional. La actividad consistió en trabajar con Git y GitHub mediante la creación de un repositorio, procurando documentarlo y organizarlo correctamente.

## Trabajo integrador

El trabajo integrador consiste en desarrollar un **sistema de control de inventario para una ferretería**, utilizando Python.

El programa permite administrar las herramientas disponibles y sus existencias mediante un menú interactivo que contempla las siguientes operaciones:

- Cargar herramientas con sus existencias iniciales.
- Mostrar el inventario completo.
- Consultar el stock de una herramienta.
- Identificar herramientas agotadas.
- Agregar nuevas herramientas.
- Actualizar existencias mediante ventas o ingresos de mercadería.
- Finalizar la ejecución del programa.

Para su desarrollo se aplican listas de diccionarios, funciones, estructuras condicionales y repetitivas, validaciones de datos y manejo de excepciones mediante `try`, `except` y `raise`.

El inventario se mantiene en memoria durante la ejecución del programa, sin almacenamiento permanente en archivos o bases de datos.

El trabajo también contempla la documentación del diseño de la solución mediante un informe de fundamentación y diagramas de flujo, además de un video explicativo sobre las decisiones tomadas durante el desarrollo.
